# 🏦 Loan Approval Prediction

A machine learning web application that predicts whether a loan application is likely to be approved based on applicant and financial information.

## 🚀 Live Demo

Add your Streamlit deployment link here after deployment.

## 📌 Project Overview

This project uses supervised machine learning to classify loan applications into:

- Loan Approved
- Loan Not Approved

The application accepts applicant information through a Streamlit interface and performs the same preprocessing and feature engineering used during model training before generating a prediction.

💻 Run Locally

Clone the repository:

git clone https://github.com/YOUR_USERNAME/loan-approval-prediction.git

Navigate to the project:

cd loan-approval-prediction

Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py
